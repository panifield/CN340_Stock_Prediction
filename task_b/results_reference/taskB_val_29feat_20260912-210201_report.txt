  - Baseline: Rolling Mean k d = ค่าเฉลี่ย return ของ k วันก่อนหน้า
    (ใช้ข้อมูลถึงวัน t-1 เท่านั้น ตรวจ leak ด้วยการคำนวณมือแล้ว)
    ไม่ใช่ตัวทำนายค่าคงที่ จึงมี StdRatio / Rho / DirAcc ให้เทียบ
    ถ้าโมเดล ML แพ้แม้แต่ตัวนี้ = หลักฐานเพิ่มว่าสัญญาณอ่อนจริง
  - R2_OOS = 1 - SSE(โมเดล)/SSE(Naive) เทียบกับคู่แข่งที่ประกาศไว้
    ต่างจาก R2_return ที่เทียบกับค่าเฉลี่ยของชุดที่ประเมินเอง
    ซึ่ง ณ เวลาทำนายยังไม่มีทางรู้ค่านั้นได้ (ต้องรู้อนาคตทั้งชุดก่อน)
  - R2_price ที่สูงมาก (>0.95) ไม่ได้แปลว่าโมเดลเก่ง
    เพราะมันมาจากการที่ราคาพรุ่งนี้ใกล้เคียงราคาวันนี้อยู่แล้ว
  - ให้ดู MAE_baht เทียบกับ Baseline: Naive (RW) เป็นหลัก
  - DirAcc นับเฉพาะวันที่ราคาขยับจริง (ตัดวันราคานิ่ง 14.09% ออก)
    เพดานสูงสุดคือ 100% ของวันที่นับ ไม่ใช่ของทั้งชุด
  - Baseline: Naive (RW) ได้ DirAcc = NaN เพราะทำนาย return = 0
    เสมอ จึงไม่ได้ให้สัญญาณทิศทาง -> ใช้ Always Up เทียบแทน
  - StdRatio / Rho / Bias แตก R2_return ออกเป็นส่วน ๆ ได้พอดี:
        R2 = 2*Rho*StdRatio - StdRatio^2 - Bias^2
    Rho คือทักษะจริง (เพดานของ R2 หลังปรับเทียบคือ Rho^2)
    StdRatio ที่เหมาะสมคือเท่ากับ Rho ถ้าสูงกว่ามาก = ทำนายแกว่งเกินจริง
    Bias สูง = train กับชุดที่ประเมินมี distribution ต่างกัน
  - Rho_lo / Rho_hi คือช่วงความเชื่อมั่น 95% ของ Rho (n = 362 วัน)
  ทักษะจริง (Rho) ต่างจากศูนย์ไหม เมื่อดูช่วงความเชื่อมั่น 95%:

    ซึ่ง ณ เวลาทำนายยังไม่มีทางรู้ค่านั้นได้ (ต้องรู้อนาคตทั้งชุดก่อน)

  - DirAcc นับเฉพาะวันที่ราคาขยับจริง (ตัดวันราคานิ่ง 18.51% ออก)
    เพดานสูงสุดคือ 100% ของวันที่นับ ไม่ใช่ของทั้งชุด

    เสมอ จึงไม่ได้ให้สัญญาณทิศทาง -> ใช้ Always Up เทียบแทน
  - StdRatio / Rho / Bias แตก R2_return ออกเป็นส่วน ๆ ได้พอดี:

    Bias สูง = train กับชุดที่ประเมินมี distribution ต่างกัน
