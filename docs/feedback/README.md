## 2. Calibration curve (feedback ข้อ 8)

reliability diagram 10 bin ของ P(คี่) ทั้งแบบที่แปลงจาก P(พลิก) และแบบ Δtick ใช้ ECE ถ่วงน้ำหนักตามจำนวนแถวในแต่ละ bin ในรูปไม่วาด bin ที่มีน้อยกว่า 5 แถว

baseline คือการทาย P(คี่) เท่ากับสัดส่วนคี่ของชุด train:
- **test/holdout:** ใช้สัดส่วนคี่ของ dev pool
- **OOF:** ใช้สัดส่วนคี่สะสมของแถวก่อนหน้า ไม่เห็นอนาคต และเริ่มที่ 0.5 ทำให้ช่วงต้นมีค่าสุดขั้วอยู่ไม่กี่แถว

**Brier (ต่ำ = ดี) บน test/holdout เทียบ baseline:**

| ชุด | โมเดล | Brier | baseline | ECE | ECE baseline |
|---|---|---|---|---|---|
| A KBANK test | LightGBM | 0.2548 | 0.2515 | 0.050 | 0.049 |
| A ADVANC test | LightGBM | 0.2559 | 0.2493 | 0.066 | 0.030 |
| A2 KBANK test | LightGBM | 0.2659 | 0.2523 | 0.098 | 0.050 |
| A2 ADVANC test | LightGBM | 0.2640 | 0.2489 | 0.114 | 0.014 |
| Δtick KBANK holdout | Δtick LightGBM | **0.2425** | 0.2540 | 0.089 | 0.065 |
| Δtick KBANK holdout | Flip LightGBM | 0.2729 | 0.2540 | 0.128 | 0.065 |
| Δtick ADVANC holdout | Δtick LogReg | 0.2585 | 0.2487 | 0.123 | 0.022 |
| Δtick ADVANC holdout | Flip ANN | 0.3212 | 0.2487 | 0.239 | 0.022 |

**สิ่งที่เห็นใน OOF:**
- **ANN และ LogReg มั่นใจเกินจริงมาก:** P(คี่) ไปถึง 0.00–1.00 ทั้งที่ทายถูกราว 50% ECE อยู่ที่ 0.09–0.25 และ Brier สูงกว่า baseline 0.02–0.08
- **LightGBM calibrate ดีที่สุด:** P อยู่ในช่วงราว 0.2–0.8 และ ECE อยู่ที่ 0.05–0.09
- **ชุดที่ Brier ต่ำกว่า baseline:** มีแค่ A2 KBANK (LightGBM −0.011, Δtick LightGBM −0.010, Flip LightGBM −0.007) ส่วนต่างนี้เท่ากับข้อมูลที่ได้จากราคา 16:00 ซึ่ง persistence ก็ใช้อยู่แล้ว

**ยืนยันข้อสรุปเดิม:**
- โมเดล flip ทุกตัวบน test มี Brier แย่กว่าการทายค่าคงที่ จึงใช้ P ของโมเดลเป็น "ความมั่นใจ" ไม่ได้ ซึ่งสอดคล้องกับผล threshold sweep เดิมที่ไม่ช่วย
- ข้อยกเว้นเดียวคือ Δtick LightGBM ของ KBANK บน holdout ที่ Brier ต่ำกว่า baseline (0.2425 เทียบ 0.2540) แต่ ECE ยังสูงกว่า

## 4. Breakeven (feedback ข้อ 10)

> **การคำนวณสมมติเท่านั้น ไม่ใช่กลยุทธ์ลงทุน:** สมมติว่าแทงคู่/คี่วันละครั้ง ทายถูกได้ +1 ทายผิดเสีย −1 และเสียค่าธรรมเนียม f ต่อครั้ง ในตลาดจริงไม่มีเครื่องมือที่จ่ายแบบนี้

breakeven accuracy = (1 + f) / 2 · กำไรเฉลี่ยต่อครั้ง = 2p − 1 − f · CI มาจาก Wilson 95% ของ p
จำนวนวันที่ต้องใช้ = n ของการทดสอบด้านเดียว H0: p = breakeven ที่ α = 0.05 และ power 80% โดยสมมติว่า accuracy ที่เห็นคือค่าจริง ซึ่งเป็นสมมติฐานที่มองโลกในแง่ดี

| f | 0% | 0.5% | 1% | 2% | 5% |
|---|---|---|---|---|---|
| breakeven accuracy | 50.0% | 50.25% | 50.5% | 51.0% | 52.5% |

**ชุด test/holdout ที่ f = 0:**

| ชุด | accuracy | กำไร/ครั้ง [95% CI] | วันที่ต้องใช้ |
|---|---|---|---|
| A KBANK LightGBM (n=365) | 50.1% | +0.003 [−0.10, +0.10] | ~790,000 |
| A ADVANC LightGBM (n=365) | 48.5% | −0.030 [−0.13, +0.07] | ไม่ถึง breakeven |
| A2 KBANK LightGBM (n=140) | 54.3% | +0.086 [−0.08, +0.25] | 838 |
| A2 KBANK persistence-1600 (n=140) | 55.0% | +0.100 [−0.07, +0.26] | 617 |
| A2 ADVANC LightGBM (n=140) | 45.0% | −0.100 [−0.26, +0.07] | ไม่ถึง breakeven |
| A2 ADVANC persistence-1600 (n=140) | 53.6% | +0.071 [−0.09, +0.23] | 1,211 |
| Δtick KBANK LightGBM holdout (n=144) | 55.6% | +0.111 [−0.05, +0.27] | 498 |
| Δtick ADVANC LogReg holdout (n=144) | 55.6% | +0.111 [−0.05, +0.27] | 498 |
| **H1: KBANK 100–200 บาท holdout (n=61)** | **63.9%** | **+0.279 [+0.03, +0.50]** | **78** |

- **ชุดที่ CI ของกำไรไม่คร่อม 0:** มีแค่ H1 และชุดพัฒนา A2 KBANK (persistence-1600 62.9% และโมเดลที่ทำได้ต่ำกว่า persistence)
- **H1 กับค่าธรรมเนียม:** CI ยังอยู่เหนือ 0 จนถึง f = 2% และคร่อม 0 ที่ f = 5%
- **ข้อควรระวังของ H1:** n = 61 และเป็นช่วงราคาย่อยที่เลือกมาจากหลายช่วง ตัวเลขนี้ยังไม่ได้แก้ Bonferroni
